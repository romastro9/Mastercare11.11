# Mastercare11.11 — Grand Opening Invitation

A mobile-friendly Khmer and English invitation for the Mastercare Grand Opening on November 11, 2026.

## Personal guest links

Add a guest name to the invitation URL with `?guest=Name`, for example `?guest=Dara`. Open the link manager with `?manage=1` to copy guest-specific links.

The site keeps the original event details, directions, dress-code guide, gift note, photo album, and calendar download.
